# Page Number Reference

Papers often have *printed* page numbers that differ from *PDF-viewer* page
numbers. A working paper may start on PDF page 1 but printed page 1; a journal
reprint may start on PDF page 1 but printed page 245.

## Rule

**When referencing a location by page number, always use the PRINTED page
number as it appears on the page itself** — not the PDF-viewer page number,
and not the `[Page N]` marker in the text dump (which is a PDF-viewer index).

Locate the printed page number by reading the header/footer of the page in
the PDF itself. If a section of the paper has no printed page number
(e.g. the title page of a working paper), either use the nearest printed
page number and note the offset, or omit the citation.

When citing supplement content, use the supplement's own numbering (e.g.
`p. S3`, `p. A-2`) rather than continuing the main-text numbering.

## Exception: code stages

For issues found in replication code (stages `01h`–`01m`, `04b`), cite a
**file name and short code quote** rather than a page number. Code has no
printed pages.
